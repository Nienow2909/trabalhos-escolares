# On Cloudsurfer 3 — motion graphic

[Baixar versão 5 — MP4, 60 segundos, Full HD](./cloudsurfer-motion-v5.mp4?raw=true)

Animação do tênis montado, abertura em quatro camadas, descrição de cada componente e remontagem. Ilustração dimensional construída com fotos oficiais projetadas em meshes, câmera suave, transições, narração em português e novos vídeos oficiais de pisada e corrida. Não é um modelo de engenharia 3D completo. Conceito criativo independente; não é uma campanha oficial da On.
